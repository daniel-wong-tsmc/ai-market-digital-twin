Why we say that

NVIDIA cut the memory on its mainstream Rubin Ultra chip to 192GB. The stated reason is that memory is scarce: less memory in each chip means more finished chips out of the same pool.

Packaging — the step that binds a chip to its memory — is easing at the same time. The shortfall there narrowed from about 20 percent to about 10 percent as TSMC output climbs toward 125,000–130,000 wafers a month. So the ceiling has moved rather than lifted.
